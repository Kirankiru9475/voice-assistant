# Voice Assistant

A voice-controlled laptop assistant built with Python and Ollama.

## What it does
- Listens to spoken commands through the microphone
- Uses a local llama3.2 model to understand them
- Opens apps, websites and plays YouTube songs

## Requirements
- Python 3.12, Ollama with llama3.2
- pip install ollama SpeechRecognition pyttsx3 pyaudio pywhatkit

## How to run
